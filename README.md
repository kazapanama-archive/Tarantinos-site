# Tarantinos site

Link to fully working project: [link](https://tarantinos.com.ua/)

## About project

Simple site for a local burger restaurant.
Lets users read about the business and see up-to-date menu prices.
Available in Ukrainian and English.


## What I learned in the process

- How to use react-router-dom for a multi-page SPA
- How to make simple animations with framer-motion
- How to work with Swiper
- How multi-language sites are built
